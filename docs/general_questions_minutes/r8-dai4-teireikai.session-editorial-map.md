> **これは review 用の編集ドラフトです**（public JSON ではない）。議案・topic 紐付けは**候補のみ・自動確定しない**。**fuzzy matching不使用**。**本文にない背景は補完しない**。normal/hard 記事本文はまだ作らない。

- **候補**：編集者が後で確定すべき紐付け（`candidate`）。議案は原則すべて候補。
- **未確定**：anchor の item 紐付け・答弁内容・数値。**議事録原文での確認が必要（review_required）**。
- **anchor_texts**：canonical（ASR由来）の `raw_anchor_text`。質問単位であり item 単位ではない／表記揺れ・ノイズを含むため**要校正**。
